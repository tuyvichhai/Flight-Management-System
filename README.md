# Flight Management System (C++)

A comprehensive console-based Flight Management System implemented in C++. This project handles flight schedules, passenger registrations, seat allocations, booking processes, payment tracking, and analytics reporting.

## 🚀 Features

- **Flight Management:** View, search, add, edit schedules, and update flight status.
- **Passenger Management:** Register passengers, search by passport/ID, and view flight histories.
- **Booking System:** Create, search, modify, and cancel flight bookings.
- **Seat Allocation:** Interactive seat management (Business & Economy classes).
- **Payment & E-Ticketing:** Process transactions via Cash, ABA Pay, Card, or Wing, and generate e-tickets.
- **Reports & Analytics:** Revenue reports, occupancy rates, and popular destination tracking.

## 🛠️ Built With

- **Language:** C++
- **Libraries Used:** Standard Template Library (`<iostream>`, `<vector>`, `<string>`, `<iomanip>`, `<algorithm>`)
